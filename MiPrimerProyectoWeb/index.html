Cómo funciona una aplicación web

Una introducción a la ingeniería web para quienes empiezan.

Cada vez que abres una página, tu navegador (el cliente) le pide archivos a un servidor. El servidor responde con HTML, CSS y JavaScript, y el navegador los convierte en la página que ves.

Las tres piezas básicas

  • HTML: define la estructura y el contenido de la página.
  • CSS: controla el aspecto: colores, tipografía y distribución.
  • JavaScript: agrega comportamiento e interacción.

Pruébalo

Este botón usa el archivo js/main.js para cambiar el tema de la página.
