## Descripción
Página web desarrollada con HTML5 aplicando etiquetas semánticas

## Tecnologías utilizadas
- HTML5
- CSS3

## Características
- Estructura semántica.
- Navegación accesible.
- Uso de atributos alt y ARIA.
- Formularios accesibles.
- Código validado con W3C.

## Cómo visualizar
1. Descargar el proyecto.
2. Abrir el archivo index.html en cualquier navegador web.
