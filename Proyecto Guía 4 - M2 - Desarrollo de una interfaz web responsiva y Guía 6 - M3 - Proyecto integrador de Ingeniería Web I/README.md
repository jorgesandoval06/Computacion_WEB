# Instituto Horizonte
Proyecto de Ingeniería Web I (Guías 3 y 4): sitio web responsivo para una institución educativa.

## Estructura
- `index.html` – página principal (HTML5 semántico)
- `css/styles.css` – estilos (Flexbox, Grid, Media Queries)
- `js/main.js` – menú móvil, filtro, validación del formulario
- `img/` – imágenes SVG
- `docs/` – PDFs de documentación y capturas de evidencia

## Uso
Abrir `index.html` en el navegador. No requiere instalación.
